# YAML Processor

Spring Boot приложение для работы с YAML файлами согласно JSON схеме процессов.

## Возможности

- Создание, редактирование и удаление YAML файлов
- Валидация данных согласно JSON схеме
- Веб-интерфейс на Thymeleaf для модификации файлов
- Поддержка всех типов данных из схемы

## Структура проекта

```
src/
├── main/
│   ├── java/com/sber/yamlprocessor/
│   │   ├── config/          # Конфигурационные классы
│   │   ├── controller/      # REST контроллеры
│   │   ├── model/          # Модели данных
│   │   ├── service/        # Бизнес-логика
│   │   └── YamlProcessorApplication.java
│   └── resources/
│       ├── templates/       # Thymeleaf шаблоны
│       └── application.yml  # Конфигурация приложения
└── schema.json             # JSON схема
```

## Запуск приложения

1. Убедитесь, что у вас установлена Java 17+
2. Выполните команду:
   ```bash
   mvn spring-boot:run
   ```
3. Откройте браузер и перейдите по адресу: http://localhost:8080

## Использование

1. **Создание файла**: Нажмите "Создать новый файл" и заполните форму
2. **Редактирование**: Выберите файл из списка и нажмите "Редактировать"
3. **Просмотр**: Нажмите "Просмотр" для просмотра содержимого файла
4. **Удаление**: Нажмите "Удалить" для удаления файла

## Конфигурация

Настройки приложения находятся в файле `application.yml`:

```yaml
app:
  yaml:
    directory: ./yaml-files    # Директория для хранения YAML файлов
    schema-file: ./schema.json # Путь к JSON схеме
```

## Модели данных

Приложение поддерживает следующие основные модели:

- **ProcessConfig** - корневая конфигурация процесса
- **Process** - основной процесс
- **Subprocess** - подпроцессы
- **Stage** - стадии выполнения
- **Configurator** - конфигуратор стадии
- **Trigger** - триггеры запуска
- **Result** - результаты выполнения

## Технологии

- Spring Boot 3.2.0
- Thymeleaf
- Jackson YAML
